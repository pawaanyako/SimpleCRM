# SimpleCRM — приемка заказов на доставку

Простое веб-приложение для создания и просмотра заказов на доставку.

## Стек

* Backend: C#, .NET 9, ASP.NET
* База данных: PostgreSQL, Entity Framework Core
* Frontend: TypeScript, React, Vite

## Запуск

**Требования:** Docker с плагином Compose.

В корне проекта выполнить команду:

```bash
docker compose up --build
```

Приложение будет доступно по адресу `http://localhost:8080/`.

Миграции применяются автоматически при старте приложения, создавать или накатывать базу вручную не нужно.

## Экраны

### Список заказов

* Таблица со всеми заказами: номер заказа (генерируется автоматически), маршрут (откуда → куда), вес груза и дата забора
* Кнопка «Добавить заказ»
* Клик по строке открывает карточку заказа

### Карточка заказа в режиме чтения

* В заголовке номер заказа вида `ORD-000001`
* Таблица со всеми полями заказа: города и адреса отправителя и получателя, вес груза, дата забора
* Кнопка «Назад к списку»

### Форма создания заказа

* Шесть обязательных полей: города и адреса отправителя и получателя, вес груза, дата забора
* Серверная валидация: поле с ошибкой подсвечивается, под ним выводится сообщение
* Кнопка «Отправить» блокируется на время запроса
* Кнопка «Назад к списку»

## Режим разработки

**Требования:**

* Docker с плагином Compose — для базы данных
* .NET SDK 9.0
* Node.js 20.19+ или 22.12+

Запуск состоит из трех шагов.

**1. База данных.** В корне проекта выполнить:

```bash
docker compose up db
```

**2. Серверная часть.** В корне проекта выполнить:

```bash
dotnet run --project src/api
```

API поднимется по адресу `http://localhost:5105/`. Миграции применяются автоматически при запуске.

**3. Клиент.** Открыть терминал в директории `src/client`. Перед первым запуском установить зависимости:

```bash
npm install
```

Затем запустить:

```bash
npm run dev
```

Клиент будет доступен по адресу `http://localhost:5173/`. Запросы к `/api` он проксирует на серверную часть, поэтому она должна быть запущена.

## API

| Метод | Путь | Назначение | Ответ |
| --- | --- | --- | --- |
| POST | `/api/orders` | Создать заказ | `201`, `400` при ошибке валидации |
| GET | `/api/orders` | Получить список всех заказов | `200` |
| GET | `/api/orders/{id}` | Получить заказ по идентификатору | `200`, `404` если заказ не найден |
